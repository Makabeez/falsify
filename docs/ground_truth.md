# Compiler vs. ground truth

Generated by `falsify groundtruth`. The reference rules in `corpus/ground_truth.yaml` were drafted from the claim text alone by a separate agent that never saw the compiler's output, then reviewed by a trader (`reviewed: true`, reasons in `reviewer_note`). The trader saw the draft and the compiled rules side by side, so where the reference was changed in review, the note says why. This measures how often Muse Spark's compiled rules say the same thing as the trader's reading.
